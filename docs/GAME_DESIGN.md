# 游戏设计 v1.6

## 核心循环

移动躲避 → 自动照亮虫影 → 拾取金色微光 → 暂停选择三选一能力 → 更密的虫影 → 存活至黎明或生命归零 → 结算、再来一局。

## 规则

| 时长                | 180 秒                 | 90 秒  |
| 基础生命 / 速度     | 100 / 175 世界单位每秒 | 相同   |
| 萤火基础伤害 / 间隔 | 16 / 0.66 秒           | 相同   |

| 巨蛾生命            | 750                    | 420    |
| 正式手记            | 计入                   | 不计入 |

地图 2000 × 1500 世界单位，摄像机跟随，边缘限制移动。子弹速度 460；瞄准范围随当前 Canvas 可见尺寸变化，桌面最大 520，手机更短。冲刺基础冷却 3.8 秒、免伤 0.42 秒；沿路每次冲刺只可击退并伤害每只敌人一次，普通受伤后免伤 0.85 秒。开局给 5 颗不消失的露光，每颗 3 XP；开局需求为 13 XP，可在就地拾取后获得第一次升级。敌人生成在当前屏幕外缘之外且至少距离玩家 280 单位，避开地图越界方向。

## 成长

每局可在升级暂停时换一组能力一次，不消耗经验、不推进时间、不改变已获得的能力。优先抽取本次没有显示的未满级能力；剩余池较小时允许保留部分原选项，但至少提供一个新选项。没有替代选项时不消耗次数。

第 L 级的升级需求为 `8 + L × 5` 经验；多余经验保留。最多展示三种未满级能力。每次升级只应用当前选择，所有能力都保存于本局 build，不跨局增强。

## 敌人

- 灰紫小螨：基础追逐单位，2 经验。
- 青灰甲虫：更慢、更厚，4 经验，第 22 秒后加入。
- 淡紫飞影：更快、生命较低，3 经验，第 45 秒后加入。
- 噬光巨蛾：单次出现，40 经验。击败可加快后期成长，非获胜强制条件。

普通敌人的生命与速度随局内时间缓慢增加。屏幕实体与经验物体数量受限，避免长时间积累失控。

## v1.1 手感与性能调整

- 游戏使用固定 1/60 秒模拟步进，单次刷新最大追赶 0.1 秒；对后台切换清空积累时间。
- 手机游戏期间将画面扩展到近乎全屏；可使用固定摇杆或在游戏画面左半侧开始拖动。
- HUD 最快每 80ms 更新一次，文本、无障碍属性与血条值不变时不触发 DOM 更新。菜单桌面最多绘制 30 次/秒、触屏 20 次/秒；游玩不额外限帧。
- 粗略性能回归在 120 个受控 60Hz 帧中，HUD DOM 变更数由 720 降至 4；这不是物理设备 FPS 测量。
- 20 个固定种子模拟覆盖桌面 / 手机视野大小及标准 / 练习模式，均能到达黎明。模拟策略主动追逐经验、避开近身敌人、必要时使用冲刺；不代表真人获胜率或难度。

## 范围边界

v1.2 摄像机允许有限观察地图外侧林地，移动边界仍为原地图；角色在地图角落也保留 HUD / 触控安全距离。巨蛾在画外时给方向提示。冲刺触发即确定方向，持续 0.19 秒，移动倍率 4.5；调度器最多同时容纳 145 个敌人，巨蛾出现前预留一个名额。

没有多人联机、在线排行或跨局付费增强。当前数值为首版，需要真实玩家继续调优。练习的目标是让第一次接触此类型的玩家熟悉移动和拾取。

## v1.3 生长与复盘

暂停和图鉴可查看当前生命、萤火伤害 / 频率 / 枚数、移速、吸引范围、叶环伤害和冲刺冷却；能力说明与规则共享 UPGRADES 数据。最近八局足迹区分守夜 / 练习，以及获胜 / 受击结束 / 主动结束。正式纪录仍仅计算守夜。结算可按原模式与种子重试，视口、输入和成长选择会改变实际进程，因此不承诺逐帧复现。

普通敌人靠近时柔性分离，提升虫群轮廓可读性；目标间距为半径和的 72%，单步分离最多 95 × dt 世界单位。巨蛾不参与位移修正，避免改变蓄力路线。分离不消耗随机数。角色死亡立即停止当帧后续子弹、经验处理，最终得分不会在结算后变化。

## v1.4 开局与战斗反馈

三位守夜人从开始即可选择，无需解锁；属性仅影响本局，没有跨局增强。提灯沿用原数值；护叶生命 110、伤害 13、移速 165、冲刺冷却 4.2 秒，自带每 0.55 秒 6 点近身叶环；逐风生命 85、伤害 14、移速 200、冲刺冷却 2.9 秒。护叶的初始叶环不占用成长等级，选择护身叶仍每级增加 10，最多 4 级。正式纪录共用，足迹保存角色；同种子重试保留角色、模式与随机起点。

子弹按这一帧有效存活时间内的路径计算最早交点，单枚仅命中一个目标。敌人与角色按相对路径检查接触；巨蛾俯冲位移为 330 × 0.6 = 198 单位，受世界边界约束。蓄力 / 俯冲期间不被击退，粉色带和边线包含双方半径之和，提示角色中心需要离开的范围。预警先于角色绘制，画外来源的可见路线仍会显示。

选择升级后获得至少 0.65 秒免伤，减少阅读选项后瞬间受伤；不推进时钟、不消耗冲刺。角色脚边有冲刺恢复弧，受伤敌人的血条在存活期间保留。回血和伤害显示实际生命变化；轻量模式保留受伤 / 回血数字、取消普通伤害数字。结算统计有效伤害、承受伤害、实际回血、冲刺次数、拾取经验；溢出伤害不计，练习仍不改正式纪录。角色数值与整体难度尚需真人验证。

## v1.5 中断与成长理解

游玩每 4 秒及暂停、升级 / 换选、后台 / 离开页面时暂存当前局；同一标签页刷新后可继续。恢复不推进离线时间，先暂停，若正在升级则保留原选项、XP、能力等级与剩余换选。随机源保持当前序列位置，保留敌群、子弹、微光和巨蛾预警 / 俯冲状态；恢复本身不刷新生命、冲刺或加给额外经验。尺寸改变时更新生成 / 瞄准范围，因此跨视口后续行为仍可能分叉。

暂停菜单可暂存并返回花园，开始另一局需要确认替换。结束 / 获胜后清除暂存，正式成绩仅结算一次。暂存属于当前标签页，关闭后不保证保留，不是跨设备云存档；异常中止页面可能回到最近一次暂存。暂存失败时明确提示并保持当前局，不自动切回菜单。

升级提示解释当前已拥有的多发 / 叶环与备选能力的配合；生命类显示此刻实际可恢复生命，上限取变化后的生命上限。提示不自动替玩家选择，也不改变抽取权重和原角色数值。微光超出 240 时立即合并，保持 XP 总和；旋转 / 尺寸变化清理旧方向输入。

## v1.6 每日守望与分享

每日守望沿用标准 180 秒、刷怪和伤害规则。按北京时间日期 `YYYY-MM-DD` 对 `mosslight:daily:v1:<日期>` 进行固定 FNV-1a 32 位散列，种子由此确定；用该种子独立读取一次 RNG 选择守夜人，不额外消耗本局随机序列。种子和角色映射测试固定了 2026-11-24 的基准。相同日期 / 版本提供相同起点；视口、输入和升级仍影响实际进程，不能当成严格相同的比赛录像。

每日结果不改变普通守夜的 score / wins / bestTime / runs。独立日记录保存最近 14 个日期的最高微光、最长时间、尝试 / 成功次数，八局足迹带日期。结束、再次挑战、暂存跨午夜和从旧链接开始都归入原日期，不自动切到新一天。每日入口及打开的说明在北京时间午夜更新；正在进行的 Game 不改变。

摘要来自真实结算：版本、模式 / 每日日期、角色、结果、得分、时长、等级、击杀、冲刺、能力和种子。挑战链接只带普通模式 / 角色 / uint32 种子，或每日日期。打开后只显示主动开始按钮；有待续进度仍确认替换。不包含成绩认证、联网排行、遥测或自动发送功能。剪贴板写入只响应复制按钮，拒绝后可选中文本手动复制。
